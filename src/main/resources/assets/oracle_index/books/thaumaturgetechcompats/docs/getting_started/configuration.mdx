---
title: Configuration and Toggles
icon: minecraft:comparator
---

Every number the pages mention (capacities, rates, durabilities, ranges, costs) can be changed in the configuration files of the mod.

Every feature has its own on/off toggle in the compatibilities file of the mod configuration. Turning one off removes its recipes and research, and most toggles need a game restart. Nothing is mandatory: install only the mods you like.

JEI shows an information page for every block and item of this mod, and Jade shows block information.
