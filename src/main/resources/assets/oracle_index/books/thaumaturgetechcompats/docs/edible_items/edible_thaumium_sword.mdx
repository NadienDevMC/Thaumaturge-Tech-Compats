## What it is

Edible Thaumium Sword is a copy of an item that you can **eat**. It is food only: not a working tool, weapon, door or goggles. Eating it gives a status effect that depends on the kind of item, stronger and longer the higher its tier.

| Property | Value |
| --- | --- |
| Tier | 2 |
| Effect when eaten | Health Boost and Regeneration III |
| Effect duration | 60 seconds |
| Hunger restored | 3 |
| Saturation | 0.7 |
| Stack size | 16 |
| Can be eaten with a full hunger bar | yes |

## How to use it

1. Craft the original item together with a Sugar at a crafting table, in any arrangement. Both are used up (enchantments of the original are not kept).
2. Hold it and keep right click pressed, like any food. It can always be eaten, even with a full hunger bar.
3. Use the effect while it lasts; eating another of the same kind refreshes it.
