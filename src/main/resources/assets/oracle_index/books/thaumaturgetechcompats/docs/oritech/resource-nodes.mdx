> [!NOTE]
> Requires **Oritech**. In the compatibilities config you can switch off the whole Oritech integration, all the nodes, or each node on its own; all on by default. Numbers are in the resource nodes section of the Oritech config and need a game restart.

## What it is

Three resource nodes that work like Oritech's own: bedrock-like veins that Oritech's Deep Drill can bleed forever.

| Node | Gives | Made from Oritech node | World rarity (default) |
| --- | --- | --- | --- |
| [](@thaumaturgetechcompats:resource_node_cinnabar) | raw cinnabar | Redstone resource node | 1 chunk in 400 |
| [](@thaumaturgetechcompats:resource_node_amber) | amber | Gold resource node | 1 chunk in 500 |
| [](@thaumaturgetechcompats:resource_node_quartz) | quartz | Lapis resource node | 1 chunk in 400 |

## How to get it

Two ways:

1. **In the world**: they generate in the overworld like Oritech's nodes, with a boulder of deepslate on the surface. Each is generated in 1 of every N chunks (world generation rarity, higher is rarer).
2. **Infusion altar**: research **Resource Nodes of Thaumaturge**. Catalyst: the matching Oritech node. Components: four Thaumaturge ores (cinnabar ore, amber ore, quartz ore) alternating with four products (raw cinnabar, amber, quartz). Aspects: 16 permutatio, 12 metallum, 12 terra. Instability 4.

## Step by step

1. Find or infuse the node.
2. Place the node block (or find the one in the world) where the Oritech Deep Drill can reach it.
3. Build the Oritech Deep Drill over the node and power it as Oritech asks.
4. The drill produces the node's product every cycle, forever. Default is 1 item per cycle, the same as Oritech's own nodes.
5. Change the amount (1 to 64) with the production setting of each node.

> [!TIP]
> The node can be drilled endlessly: you only need to keep the Deep Drill powered.

## Common mistakes

- Expecting the node to be consumed. It is not.
- Looking for them in other dimensions: they generate in the overworld.
- Changing the production or the world generation rarity without restarting.

## Notes

- It can be turned off in the mod's configuration (compatibilities file).
- Its values are adjusted in the mod's Oritech configuration.
