## What it is

The Thaumium Basin works **exactly like the Create machine it is made from**: same recipes, same kinetic needs, and it appears as a catalyst in the same JEI categories. The only difference: while an aura node is within reach it works many times faster, with enchant particles above it. Away from every node it behaves as the plain machine.

| Property | Value |
| --- | --- |
| Speed while a node is in reach (default) | 15 times faster |
| Node reach (default) | 10 blocks |

## How to use it

1. Research the machinery entry of its tier and make the casing of that tier.
2. Infuse the variant over the machine of the tier before (the plain Create machine for Alchemical Brass).
3. Place it **instead of** the plain machine and connect it to your kinetic network the same way (shafts, cogs, belts).
4. Make sure an aura node is within its reach: it looks for the nearest node by itself every 20 ticks.
5. Build the rest of the line as usual (belts, funnels, basins).
