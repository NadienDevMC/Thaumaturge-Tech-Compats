---
title: Aspects of Botania Items
---

> [!NOTE]
> Requires **Botania** (Botania Revived). The aspects of Botania items (and the whole Botania integration) can be switched off in the compatibilities config; on by default, game restart needed.

## What it is

Botania items have no aspects in Thaumaturge, so you cannot scan or break them down in the crucible. This feature gives aspects to the items of Botania: its metal and gem blocks, quartzes, glass, cloth, seeds, livingwood and dreamwood, livingrock, manaweave armor, flowers and other materials, almost always with a touch of **praecantatio** (the aspect of magic).

Examples (aspect amounts shown by the tooltip):

| Item | Aspects |
| --- | --- |
| Manasteel Block | metallum 40, praecantatio 15 |
| Elementium Block | metallum 40, permutatio 20, praecantatio 20 |
| Terrasteel Block | metallum 40, terra 20, praecantatio 15, victus 10 |
| Mana Diamond Block | vitreus 30, desiderium 20, praecantatio 15 |
| Livingwood Twig | herba 3, praecantatio 1 |
| Dreamwood Twig | herba 3, aer 1, praecantatio 2 |
| Livingwood | herba 20, victus 3, praecantatio 3 |
| Frozen Star | gelum 10, lux 5, praecantatio 3 |

## How to use it

1. Read the aspects of the item the same way you read those of any other item in Thaumaturge.
2. Use the item in the crucible, scanning or infusion exactly like any item with aspects.
3. This is data only: there is no block or item to craft.

## Common mistakes

- Expecting aspects on Botania items with the toggle off.
- Not restarting after changing the toggle.

## Notes

- It can be turned off in the mod's configuration (compatibilities file).
