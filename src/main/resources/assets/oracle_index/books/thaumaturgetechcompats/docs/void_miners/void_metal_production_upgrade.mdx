## What it is

The Void Metal Miner Production Upgrade goes in a modifier slot of a Void Miners structure. Upgrades **multiply** with each other and with Void Miners' own modifiers.

| Property | Value |
| --- | --- |
| Goes in | miner (items) |
| Multiplier | 1.5 |

## How to use it

1. Craft it at the Arcane Workbench around the same upgrade of the tier before (for Thaumium, the matching Void Miners modifier).
2. Put it in a modifier slot of the right kind of structure (miner upgrades in miners, solar upgrades in solar panels).
3. Stack several: their multipliers multiply.

> [!NOTE]- Thaumonomicon: Void Metal Miner Upgrades
> Every Void Metal upgrade is made on an arcane workbench from the same upgrade of the Alchemical Brass tier, two void metal mechanisms and two plates.
> Place them in the free slots of the structure. Their effects multiply with each other and with the real Void Miners modifiers, and the cost ones lower the aura units the miner pays to its power source.
