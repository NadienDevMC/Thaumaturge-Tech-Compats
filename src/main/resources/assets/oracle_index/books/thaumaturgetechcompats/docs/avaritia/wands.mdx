> [!NOTE]
> Needs the **Avaritia** mod. The Infinity wand is built in Avaritia's Extreme Crafting Table.

## What it is

Three tiers of wand parts. Any rod fits any cap, so you can mix them, but the best wands use the same tier for both.

| Part | Effect | Vis stored (rod) |
| --- | --- | --- |
| [](@thaumaturgetechcompats:matrix_wand_rod) | channels vis without losing any | 1000 |
| [](@thaumaturgetechcompats:matrix_wand_cap) | makes spells cost nothing | - |
| [](@thaumaturgetechcompats:neutronium_wand_rod) | holds far more vis and wastes far less | 5000 |
| [](@thaumaturgetechcompats:neutronium_wand_cap) | cuts the cost of every spell by half (cost modifier 0.5) | - |
| [](@thaumaturgetechcompats:infinity_wand_cap) | makes spells free; with the Infinity rod the wand also refills every primal aspect on its own | - |

A wand built with Crystal Matrix parts holds 1000 vis and its spells cost nothing; with Neutronium parts it holds 5000 vis and spells cost half.

## How to get them

| Part | How |
| --- | --- |
| Crystal Matrix Rod | arcane workbench (300 vis): three Crystal Matrix Ingots in a diagonal |
| Crystal Matrix Cap | arcane workbench: three Crystal Matrix Ingots on top and two Crystal Matrix Plates below, leaving the middle empty |
| Neutronium Rod | infusion altar, catalyst Crystal Matrix Rod, two Neutron Ingots and two Neutronium Plates (Terra 32, Praecantatio 24, Potentia 24, Terminus 8; instability 8) |
| Neutronium Cap | infusion altar, catalyst Crystal Matrix Cap, two Neutron Ingots and two Neutronium Plates (Potentia 24, Metallum 24, Auram 12, Terminus 8; instability 6) |
| Infinity Cap | infusion altar, catalyst Neutronium Cap, four Infinity Ingots and two Infinity Plates (Praecantatio 48, Alienis 32, Potentia 32, Terminus 24; instability 10) |
| Infinity Wand | Extreme Crafting Table, tier 4 (see below) |

## The Infinity wand

It is too grand for an arcane workbench. The pattern is a diagonal sweep, with C = Crystal Matrix Ingot, N = Neutron Ingot, I = Infinity Ingot and X = Block of Infinity (the Avaritia "infinity" block):

```
- - - - - - C - -
- - - - - C I C -
- - - - - N I I C
- - - - N I N C -
- - - N X N - - -
- C N I N - - - -
C I I N - - - - -
- C I C - - - - -
- - C - - - - - -
```

The result is a wand with the Infinity rod and the Infinity cap.

## Step by step

1. Finish the research "Crystal Matrix Wand", then "Neutronium Wand", then "Infinity Wand" (the last needs the Akashic Records researched).
2. Craft the Crystal Matrix rod and cap, then assemble them into a wand as with any Thaumaturge wand.
3. Infuse the Neutronium parts using the Crystal Matrix parts as catalysts, on an altar whose center is the right Runic Matrix.
4. Infuse the Infinity Cap on a Neutronium Cap, then craft the full Infinity wand in the Extreme Crafting Table.

## Common mistakes

- Forgetting the catalyst: each tier needs the part of the tier before it.
- Trying to craft the Infinity wand in the arcane workbench: it only exists as an Extreme Crafting Table recipe.
