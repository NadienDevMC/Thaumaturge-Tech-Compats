> [!NOTE]
> Each potion can be switched off in the purity section of the compatibilities config. The Potion of Absolution needs the Potion of Clarity. Settings are in the warp potion config.

## What they are

Two drinkable potions that remove warp from the drinker.

| | [](@thaumaturgetechcompats:clarity_potion) | [](@thaumaturgetechcompats:absolution_potion) |
|---|---|---|
| Removes | temporary warp | permanent warp |
| Amount | all of it in one drink (default) | 1 point per drink by default (the remove all setting is off) |
| Side effect (default) | Nausea for 100 ticks | Weakness II for 1200 ticks |
| Cooldown between drinks | 20 ticks | 100 ticks |
| Returns the glass bottle | yes | yes (config) |

Every value (amount, remove all, side effect, duration, cooldown, bottle) can be changed in the config. Clarity can also be set to remove ordinary (sticky) warp.

## How to get them

Both are brewed in a crucible.

- **Clarity Potion**: Cognitio 60, Ordo 50, Spiritus 40, Aqua 40, Victus 30, Alienis 20, with a **Sanity Soap** as the catalyst.
- **Absolution Potion**: Cognitio 100, Ordo 100, Spiritus 80, Alienis 80, Praecantatio 80, Vacuos 60, Tenebrae 60, Victus 60, Auram 50, Perditio 40, with an **Eldritch Eye** as the catalyst.

## Step by step

1. Complete the research of each potion.
2. Brew it in a crucible with the catalyst.
3. Drink it. Clarity clears temporary warp at once; with Absolution, drink as many as it takes.

## Common mistakes

- Expecting Clarity to remove permanent warp: it does not touch it.
- Expecting one Absolution to free you: each draught removes only a measure, and it leaves you weakened for a long while.

## Notes

- It can be turned off in the mod's configuration (compatibilities file).
- Its values are adjusted in the mod's warp potion configuration.
