## What it is

The Neutronium Mnemonic Matrix is a Mnemonic Matrix of Neutronium: placed against a Thaumatorium it lets it remember more formulas at the same time. It stacks with ordinary matrices and loses no formula.

| Property | Value |
| --- | --- |
| Simultaneous formulas added (default) | 6 |

## How to use it

1. Research Mnemonic Matrices of Avaritia.
2. Infuse it over the matrix of the tier before, with the Runic Matrix of its tier at the center of the altar.
3. Place it against the Thaumatorium like an ordinary Mnemonic Matrix.
4. Look at it with Jade to see how many formulas it adds.
