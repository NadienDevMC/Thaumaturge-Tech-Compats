> [!NOTE]
> The pearls need the **Avaritia** mod; the Blaze Cube, Crystal Matrix, Neutronium and Infinity tiers too.

## What it is

The Creative Planetary Endest Pearl is thrown like an ender pearl and summons **planets** that orbit what it hits and hurt it again and again until they fade. The planets never hurt the thrower or the thrower's pets.

| Property | Value |
| --- | --- |
| Planets | 12 |
| Damage per planet hit | 40.0 |
| Hits every | 0.2 seconds |
| Lasts | 60 seconds |
| Orbit radius (blocks) | 4.5 |
| Cooldown | 0.5 seconds |
| Durability | unbreakable |
| Damage cap against bosses | kills bosses |

## How to get it

It has no recipe: it only exists in the creative tab.

## How to use it

1. Research Planetary Endest Pearl and The Great Orbits, then infuse it with the pearl of the tier before as the central item (an Avaritia Endest Pearl for Copper). From Blaze Cube on it also asks for Salis Mundus variants. The Creative pearl has no recipe.
2. Throw it with right click.
3. If it hits a creature, the planets orbit that creature; if it hits a block, they orbit the closest creature within 6 blocks, or the point of impact.
4. Wait for the cooldown before throwing again. Every throw wears one point of durability, unless the pearl is unbreakable.
