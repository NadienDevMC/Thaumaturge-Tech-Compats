## What it is

The Crimson Block is nine ingots of the metal in one block, for storage. It melts in the Hephaestus smeltery and can be cast in a casting basin.

## How to use it

1. Craft it from nine ingots, or pour the molten metal into a casting basin.
2. Place it or keep it in storage; a block crafts back into nine ingots.
