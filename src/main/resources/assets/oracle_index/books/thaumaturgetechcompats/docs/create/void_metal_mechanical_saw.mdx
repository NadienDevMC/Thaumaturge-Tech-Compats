## What it is

The Void Metal Mechanical Saw works **exactly like the Create machine it is made from**: same recipes, same kinetic needs, and it appears as a catalyst in the same JEI categories. The only difference: while an aura node is within reach it works many times faster, with enchant particles above it. Away from every node it behaves as the plain machine.

| Property | Value |
| --- | --- |
| Speed while a node is in reach (default) | 15 times faster |
| Node reach (default) | 16 blocks |

## How to use it

1. Research the machinery entry of its tier and make the casing of that tier.
2. Infuse the variant over the machine of the tier before (the plain Create machine for Alchemical Brass).
3. Place it **instead of** the plain machine and connect it to your kinetic network the same way (shafts, cogs, belts).
4. Make sure an aura node is within its reach: it looks for the nearest node by itself every 20 ticks.
5. Build the rest of the line as usual (belts, funnels, basins).

> [!NOTE]- Thaumonomicon: Void Metal Machinery
> The void metal variants are the finest, and answer a node from the greatest distance.
> 
> **Void Metal Casing**
> 
> It is infused over a thaumium casing with four void metal plates and a complex mechanism.
> 
> **Machine variants**
> 
> Each variant is infused over the thaumium variant of the same machine, with a void metal casing, two void metal plates and a complex mechanism.
