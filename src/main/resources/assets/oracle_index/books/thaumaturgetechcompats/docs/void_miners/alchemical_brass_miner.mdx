## What it is

The Alchemical Brass Miner Controller is the controller of a Void Miners miner that takes **no FE at all**: it works only while it can pay a few units of power to a magical source close by, and stops the moment it cannot. It is a multiblock like the Rubetine miner: the controller plus frames, glass panels and modifier slots.

| Property | Value |
| --- | --- |
| Mining tier (Void Miners recipes) | 5 |
| Speed multiplier | 3.0 |
| Production multiplier | 2.0 |
| Units paid every 20 ticks | 2 |
| Power source radius | 12 blocks |
| Modifier slots of its structure | 4 |

## How to use it

1. Research the Magical Miner entry of its tier (Tech tab) and infuse it over the controller of the tier before (the Rubetine Miner for Thaumium).
2. Craft the Alchemical Brass miner frames and build the multiblock of the tier around the controller, with Void Miners glass panels and modifier slots.
3. Place a power source within the radius: a jarred node, a Flux Jar, a Rift Jar, a world node or a flux rift (never a hungry node).
4. Every 20 ticks it pays its units: while paid it mines, otherwise it waits for the next try.
5. Take the output as from any Void Miners miner.

> The Alchemical Brass Miner Controller is made on an infusion altar from the Thaumium Miner Controller, alchemical brass plates, mechanisms and Flux Jars.
> Its frames are made on an arcane workbench from alchemical brass plates, obsidian and the matching Thaumium frame. The structure is built out of these frames, glass panels and any miner modifier, and it takes no energy at all: it works only while it can pay units to a magical power source close by, and stops the moment it cannot. A hungry node is never a valid source.
