## What it is

The Thaumium Casing is the base of the Thaumium variants of the Create machines of this mod. It does nothing on its own: you spend one, together with the machine of the tier before, to infuse a variant that runs many times faster near an aura node.

| Property | Value |
| --- | --- |
| Node reach (default) | 10 blocks |

## How to use it

1. Research the machinery entry of its tier (Tech tab): Alchemical Brass Machinery, then Thaumium Machinery, then Void Metal Machinery.
2. Make the casing (the Alchemical Brass one at the Arcane Workbench, the others infused over the casing of the tier before).
3. Keep one casing for every machine variant of that tier you want: each variant consumes one.
