> [!NOTE]
> The values are fixed in the code and are not configurable.

## What it is

The effect depends on the **kind** of item; how strong it is depends on its **tier** (0 to 3).

| Kind | Effect | Stack |
| --- | --- | --- |
| Pickaxe | Haste | 16 |
| Sword, spear and mace (weapons) | Health Boost and Regeneration | 16 |
| Axe | Speed | 16 |
| Hoe | Luck | 16 |
| Shovel | Jump Boost | 16 |
| Goggles of Revealing | Night Vision | 16 |
| Ingot | Absorption | 64 |
| Gem | Night Vision | 64 |
| Door | Resistance | 64 |

The tier is the **amplifier** of every effect, so tier 0 is level I, tier 1 is level II, tier 2 is level III and tier 3 is level IV.

| Tier | Effect level | Duration | Hunger | Saturation |
| --- | --- | --- | --- | --- |
| 0 | I | 30 s | 1 | 0.3 |
| 1 | II | 45 s | 2 | 0.5 |
| 2 | III | 60 s | 3 | 0.7 |
| 3 | IV | 75 s | 4 | 0.9 |

## Which item has which tier

| Tier | Items |
| --- | --- |
| 0 | wooden, golden and stone tool sets; Goggles of Revealing; Gold Ingot; all gems; all doors |
| 1 | copper and iron tool sets; Copper Ingot, Iron Ingot, Alchemical Brass Ingot |
| 2 | diamond, Thaumium and Elemental tool sets; the Mace; Thaumium Ingot |
| 3 | Netherite and Void Metal tool sets; Netherite Ingot; Void Metal Ingot |

A tool set is the pickaxe, sword, spear, axe, hoe and shovel (the Elemental set from Thaumaturge too).

## Step by step

1. Choose the effect you need: for example an Edible Netherite Pickaxe for Haste IV, or an Edible Void Metal Ingot for Absorption IV.
2. Craft it with sugar.
3. Eat it (it can always be eaten) and use the effect for its duration.
4. Eating several of the same kind refreshes the effect, as with any potion effect.

## Common mistakes

- Expecting a golden sword to be better than a diamond one: golden is tier 0, diamond is tier 2.
- Forgetting that the effect level is tier plus one, so tier 3 is level IV, not level III.
