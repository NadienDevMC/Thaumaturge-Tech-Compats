**Thaumaturge Tech Compats** ties Thaumaturge magic to other mods: Avaritia progression, flux power, machines powered by nodes, and three metal tiers that every compat follows: **Thaumium, then Alchemical Brass, then Void Metal**. Every tier needs the one before it.

Use the chapters on the left. **Content** has one page per feature and tells you what it is, how to get it and how to set it up step by step. Pages say which mod they need: if you do not have that mod, the feature is simply not there.

**How to open this book:** press **H** (the Oracle Index key, changeable in Controls under "Oracle Index") or hover over any item of this mod and use the item tooltip link. It is a client-side viewer: there is no book item to craft.

Almost everything is made with the Thaumonomicon research system. Each page tells you which research unlocks it.
