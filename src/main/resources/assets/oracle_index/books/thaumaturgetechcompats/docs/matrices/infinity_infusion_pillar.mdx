> [!NOTE]
> Needs the **Avaritia** mod.

## What it is

The Infusion Pillar (Infinity) is the pillar of a tiered infusion altar. It appears when Salis Mundus wakes a structure built with Infinity Pillar Stones. When all four pillars are of this tier, the altar costs less and works faster.

| Property | Value |
| --- | --- |
| Altar cost change | -0.2 |
| Cycle time change | -3 |
| Stability (plain Runic Matrix only) | +0.5 |

## How to get it

It is not crafted: it forms when Salis Mundus wakes an altar built with its Pillar Stones (see the steps below).

## How to use it

1. Craft Infinity Pillar Stones.
2. Build the eight-stone altar structure with a pedestal in the middle and a Runic Matrix.
3. Sprinkle Salis Mundus: the stones become these pillars.
4. Use the four pillars of the same tier to get the bonus.
