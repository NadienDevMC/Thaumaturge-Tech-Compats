## What it is

The Alchemical Brass Casing hums beside an aura node. Built into the machines of Create it makes variants that work many times faster while a node is near.

## How to get it

### Alchemical Brass Machinery

The casing hums beside a node. Built into a machine of Create it makes a variant of that machine: a mechanical press, mixer, saw or drill, a deployer, millstone, basin, spout, item drain or depot that works exactly like the original.

While an aura node is near, the variant works many times faster. Away from every node it behaves as the plain machine.

#### Alchemical Brass Casing

It is made at the arcane workbench from a brass casing of Create and four brass plates.

#### Machine variants

Each variant is infused over the matching machine of Create, with an alchemical brass casing and two brass plates.

### Thaumium Machinery

The thaumium variants reach nodes from farther away than the alchemical brass ones.

#### Thaumium Casing

It is infused over an alchemical brass casing with four thaumium plates and a simple mechanism.

#### Machine variants

Each variant is infused over the alchemical brass variant of the same machine, with a thaumium casing, two thaumium plates and a simple mechanism.

### Void Metal Machinery

The void metal variants are the finest, and answer a node from the greatest distance.

#### Void Metal Casing

It is infused over a thaumium casing with four void metal plates and a complex mechanism.

#### Machine variants

Each variant is infused over the thaumium variant of the same machine, with a void metal casing, two void metal plates and a complex mechanism.

## Step by step

1. Complete the matching research entry in the Thaumonomicon (Avaritia, Tech or Purity tab); without it the recipe stays locked.
2. Craft the Alchemical Brass Casing at an arcane workbench from a Brass Casing of Create and four brass plates; infuse the Thaumium Casing over it and the Void Metal Casing over the Thaumium one.
3. Infuse a variant of a Create machine (press, mixer, saw, drill, deployer, millstone, basin, spout, item drain or depot) over the matching Create machine with the casing and plates listed above.
4. Place the variant in your normal Create setup; it works exactly like the original.
5. Put an aura node close by: while a node is near the variant works many times faster (Thaumium reaches nodes from farther than Alchemical Brass, Void Metal from farthest). Away from every node it behaves as the plain machine.
