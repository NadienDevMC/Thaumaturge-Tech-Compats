## What it is

The Thaumium Miner Production Upgrade goes in a modifier slot of a Void Miners structure. Upgrades **multiply** with each other and with Void Miners' own modifiers.

| Property | Value |
| --- | --- |
| Goes in | miner (items) |
| Multiplier | 1.1 |

## How to use it

1. Craft it at the Arcane Workbench around the same upgrade of the tier before (for Thaumium, the matching Void Miners modifier).
2. Put it in a modifier slot of the right kind of structure (miner upgrades in miners, solar upgrades in solar panels).
3. Stack several: their multipliers multiply.
