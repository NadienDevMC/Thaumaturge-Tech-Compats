## What it is

A Native Osmium Cluster, a chunk of raw osmium in the style of the Thaumaturge ore clusters. It is smelted for osmium or dissolved in the crucible, and it is the result of the ore-processing routes of Mekanism and of the ores of the Industrial Foregoing Laser Drill that this mod adds.

## How to get it

### Crucible

    count={1}

Drop the catalyst into a heated crucible that holds the essentia below.

| Cost | Value |
|---|---|
| Catalyst | Raw Osmium (or equivalent) |
| Essentia | Metallum ×5, Ordo ×5 |
| Research | Metal Purification |

### Enrichment Chamber

| Input | Result |
|---|---|
| Osmium Ore (or equivalent) ×1 | Native Osmium Cluster ×2 |
| Raw Osmium (or equivalent) ×3 | Native Osmium Cluster ×4 |
| Osmium Crystal (or equivalent) ×1 | Native Osmium Cluster ×1 |

### Chemical Injection Chamber

| Input | Result |
|---|---|
| Osmium Ore (or equivalent) ×1 + Hydrogen Chloride 1 | Native Osmium Cluster ×4 |
| Raw Osmium (or equivalent) ×3 + Hydrogen Chloride 1 | Native Osmium Cluster ×8 |

### Metallurgic Infuser

| Input | Result |
|---|---|
| Osmium Ore (or equivalent) ×1 + Biomass 20 | Native Osmium Cluster ×2 |
| Raw Osmium (or equivalent) ×3 + Biomass 20 | Native Osmium Cluster ×4 |

### Purification Chamber

| Input | Result |
|---|---|
| Osmium Ore (or equivalent) ×1 + Oxygen 1 | Native Osmium Cluster ×3 |
| Raw Osmium (or equivalent) ×1 + Oxygen 1 | Native Osmium Cluster ×2 |

## Step by step

1. Put a Thaumaturge cluster or ore through one of the enabled Mekanism routes (Metallurgic Infuser with Salis Mundus gives 2 clusters; the x5 route gives 5).
2. Smelt the Native Osmium or Uranium Cluster in a furnace to get the metal, or dissolve it in a crucible.
3. Enable the x2, x3 or x4 routes in the configuration only if you accept sharing machine and input with Mekanism own ore recipes.
