    **Requires:** Thaumaturge (Node Power feature)
</Callout>

Many machines of this mod do not use RF. They pay a small amount of magical power to a **power source** close by. The valid sources are:

- A **node** in the world, or a **jarred node**.
- A **Flux Jar** (flux pulled from the aura of its chunk).
- A **Rift Jar** (a rift taken apart point by point).
- An open **flux rift**.

A **hungry node** is never a valid source. Machines that use them: the Thaummotor, the magical Unearthers, the Magical Laser Drill, the magical Void Miners and Solar Panels.

Create machine variants use a different rule: they just need an aura node near them.

## Step by step

1. Pick the source that suits your base: Flux Jars if you have flux to clean up, a Rift Jar if there is an open rift, a node or jarred node for a stable supply.
2. Place the machine within reach of the source (the Jade tooltip and the machine's chat messages name the source it is using and why it stops).
3. If the machine stops, check that the source still has power: a jar can run dry and a rift can shrink away.
4. Keep nodes stabilized (see the Avaritia Node Stabilizers) so a hungry node does not appear next to your setup.
