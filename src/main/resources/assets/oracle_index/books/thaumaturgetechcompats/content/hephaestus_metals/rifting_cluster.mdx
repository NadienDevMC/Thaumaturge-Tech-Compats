## What it is

The Native Rifting Cluster is the native cluster of the metal, like the clusters of Thaumaturge.

## How to get it

This mod defines no recipe for it.

## How to use it

1. This mod defines no recipe and no world generation for it: it is only found in the creative tab or given by other content (data packs, other mods).
2. Keep it for recipes of other content that use it.
