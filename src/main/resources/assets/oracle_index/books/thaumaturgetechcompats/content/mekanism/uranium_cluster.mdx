## What it is

A Native Uranium Cluster, a chunk of raw uranium in the style of the Thaumaturge ore clusters. It is smelted for uranium or dissolved in the crucible, and it is the result of the ore-processing routes of Mekanism and of the ores of the Industrial Foregoing Laser Drill that this mod adds.

## How to get it

### Crucible

<CraftingRecipe
    slots={['', '', '', '', 'mekanism:raw_uranium', '', '', '', '']}

    count={1}
/>

Drop the catalyst into a heated crucible that holds the essentia below.

| Cost | Value |
|---|---|
| Catalyst | Raw Uranium (or equivalent) |
| Essentia | Metallum ×5, Ordo ×5 |
| Research | Metal Purification |

### Enrichment Chamber

| Input | Result |
|---|---|
| Uranium Ore (or equivalent) ×1 | Native Uranium Cluster ×2 |
| Raw Uranium (or equivalent) ×3 | Native Uranium Cluster ×4 |
| Uranium Crystal (or equivalent) ×1 | Native Uranium Cluster ×1 |

### Chemical Injection Chamber

| Input | Result |
|---|---|
| Uranium Ore (or equivalent) ×1 + Hydrogen Chloride 1 | Native Uranium Cluster ×4 |
| Raw Uranium (or equivalent) ×3 + Hydrogen Chloride 1 | Native Uranium Cluster ×8 |

### Metallurgic Infuser

| Input | Result |
|---|---|
| Uranium Ore (or equivalent) ×1 + Biomass 20 | Native Uranium Cluster ×2 |
| Raw Uranium (or equivalent) ×3 + Biomass 20 | Native Uranium Cluster ×4 |

### Purification Chamber

| Input | Result |
|---|---|
| Uranium Ore (or equivalent) ×1 + Oxygen 1 | Native Uranium Cluster ×3 |
| Raw Uranium (or equivalent) ×1 + Oxygen 1 | Native Uranium Cluster ×2 |

## Step by step

1. Put a Thaumaturge cluster or ore through one of the enabled Mekanism routes (Metallurgic Infuser with Salis Mundus gives 2 clusters; the x5 route gives 5).
2. Smelt the Native Osmium or Uranium Cluster in a furnace to get the metal, or dissolve it in a crucible.
3. Enable the x2, x3 or x4 routes in the configuration only if you accept sharing machine and input with Mekanism own ore recipes.
