## Qué es

El Sello de Create es un sello de gólem que permite a un gólem trabajar con un bloque de Create: meter los objetos que lleva, sacar objetos y (opcionalmente) hacer clic en el bloque para girar manivelas y volantes de válvula.

## Cómo se usa

1. Investiga Sello de Create (pestaña Tech) e infúndelo sobre un Sello de uso.
2. Colócalo en la cara de un bloque de Create (por defecto no se puede poner en otros bloques).
3. Abre el sello: pon el filtro (9 huecos) y las opciones Meter, Sacar, Accionar (clic) y Clic agachado.
4. Dale un gólem con el rasgo Diestro (un gólem Torpe no puede usarlo).
5. Con Sacar activado busca cada 20 ticks un objeto que coincida; con Accionar el gólem hace clic cada 8 ticks.
6. Una señal de redstone detiene el sello.

> [!NOTE]- Thaumonomicon: Sello de Create
> El sello se coloca sobre un bloque de Create y deja que un gólem lo trabaje.
> Inserta en el bloque los objetos que lleva el gólem, saca objetos de él y también puede hacer clic en el bloque, lo que gira manivelas y manillas de válvula.
> El filtro elige los objetos de cada tarea, y cada tarea se puede desactivar en las opciones del sello.
> 
> **Sello de Create**
> 
> Se infunde sobre un sello de uso con un engranaje, una lámina de latón, aleación de andesita y un mecanismo simple.
