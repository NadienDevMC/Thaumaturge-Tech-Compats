Copias comestibles de herramientas, armas, lingotes, gemas, puertas y las Gafas de revelación. Cada una es el objeto original fabricado junto con azúcar, y comerla da un efecto según el tipo de objeto y su nivel: prisa para los picos, impulso de salud y regeneración para las armas, velocidad para las hachas, suerte para las azadas, salto mejorado para las palas, visión nocturna para las gafas y las gemas, absorción para los lingotes y resistencia para las puertas.

## Paso a paso

1. Toma el objeto original (un pico de diamante, un lingote de hierro, una puerta de roble...) y ponlo en una cuadrícula de crafteo con azúcar.
2. Recoge la copia comestible. Ya no funciona como la herramienta: es comida.
3. Cómela para recibir el efecto de su clase y nivel.
