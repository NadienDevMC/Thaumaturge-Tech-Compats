## Qué es

Los Herramientas de escritura de Matriz de Cristal son una pluma y un tintero que guardan mucha más tinta que los útiles de escritura normales. Se usan igual en la mesa de investigación.

| Propiedad | Valor |
| --- | --- |
| Usos de tinta | 300 |
| Recarga | tinte negro (la pluma sobre tinte negro en una cuadrícula de crafteo) |
| Resistente al fuego | no |

## Cómo se usa

1. Investiga Útiles de escritura de Avaritia.
2. Infúndelos a partir de los útiles del nivel anterior (útiles de escritura normales para Matriz de Cristal).
3. Ponlos en la mesa de investigación como cualquier útil de escritura.
4. Recárgalos como indica la tabla de arriba.

## Se usa para fabricar

- [](@thaumaturgetechcompats:neutronium_scribing_tools)

> [!NOTE]- Thaumonomicon: Herramientas de escritura de Avaritia
> Cada juego se fabrica en un altar de infusión, partiendo de unas herramientas de escritura normales:
> - Las de Matriz de Cristal se rodean de lingotes de matriz de cristal.
> - Las de Neutronio necesitan las de Matriz de Cristal y lingotes de neutrones.
> - Las del Infinito necesitan las de Neutronio, lingotes de infinito y una Perla Extremadamente Primordial.
> Todas funcionan en una mesa de investigación igual que las normales. Las del Infinito recuperan su tinta solas mientras las llevo encima. Las de Matriz de Cristal y Neutronio se pueden rellenar con tinte negro, como las normales.

**Guías de este capítulo:** [Niveles de varita, focos y herramientas de escritura]($devices/wands-foci)
