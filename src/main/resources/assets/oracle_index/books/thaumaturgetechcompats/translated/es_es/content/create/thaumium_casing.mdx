## Qué es

La Carcasa de taumio es la base de las variantes de taumio de las máquinas de Create de este mod. No hace nada por sí sola: gastas una, junto con la máquina del nivel anterior, para infundir una variante que va mucho más rápido cerca de un nodo de aura.

| Propiedad | Valor |
| --- | --- |
| Alcance hasta el nodo (por defecto) | 10 bloques |

## Cómo se usa

1. Investiga la entrada de maquinaria de su nivel (pestaña Tech): Maquinaria de latón alquímico, luego de taumio y luego de metal del vacío.
2. Fabrica la carcasa (la de latón alquímico en la Mesa de trabajo arcana, las demás infundidas sobre la carcasa del nivel anterior).
3. Guarda una carcasa por cada variante de máquina de ese nivel que quieras: cada variante consume una.

>
