## Qué es

El Terraformador arcano de metal del vacío repinta el bioma de la zona de alrededor, columna a columna empezando por sus pies, con el bioma de su **cebo** (un objeto que representa un bioma: arena para un desierto, nieve para la tundra, un brote para un bosque).

| Propiedad | Valor |
| --- | --- |
| Radio | 64 bloques |
| Flujo dimensional que guarda | 20.000.000 |
| DF por columna de 4x4 | 1.000 |
| Columnas por ciclo | 16 |

## Cómo se usa

1. Fabrícalo (el de taumio en la Mesa de trabajo arcana, los demás infundidos alrededor del anterior).
2. Dale DF (un Núcleo de almacenamiento, un Enlace de transmisión o un Extractor de grietas tocándolo).
3. Haz clic derecho con el objeto cebo. Agáchate y haz clic derecho con la mano vacía para recuperar el cebo.
4. Haz clic derecho otra vez para ver su progreso, radio y estado. Los biomas y dimensiones bloqueados en la configuración no se tocan.

> [!NOTE]- Thaumonomicon: Terraformador arcano de metal del vacío
> El Terraformador arcano de metal del vacío se infunde a partir de uno de latón alquímico, con cuatro placas de metal del vacío, un mecanismo complejo, dos resonadores de vis y un champiñón rojo.
> Repinta el área más amplia, la más rápida y con el menor flujo por columna.
