title: Descripciones de Jade y escenas de Ponder
---

> [!NOTE]
> Las descripciones de Jade necesitan **Jade**; las escenas de Ponder necesitan una biblioteca **Ponder**. Ambas se pueden apagar en sus propios archivos de configuración (un interruptor general de Jade más uno por familia; un interruptor general de Ponder más uno por escena).

## Integración con Jade

Mira un bloque con Jade para leer lo que de otro modo la configuración ocultaría. Las familias que puedes activar o desactivar:

| Bloque | Qué muestra Jade |
|---|---|
| Fundiciones de esencia | eficiencia, intervalo de fundición |
| Estabilizadores de nodos | nivel de bloqueo, alimentación del nodo (veces más lenta), estabilización (veces más rápida) |
| Transductores de nodos | carga por tick, intervalo de pérdida sin redstone |
| Hornos alquímicos | velocidad (veces más rápido), ahorro de calor, perditio y aqua |
| Matrices Mnemotécnicas | fórmulas simultáneas que añade |
| Cargadores de Mesa | descuento de vis, radio de vis en chunks |
| Núcleo de almacenamiento de flujo | estructura, energía, celdas de capacidad, puntos de estabilizador |
| Máquinas mágicas de Void Miners | fuente de aura, coste de aura, generación, mejoras, y por qué se detiene una máquina (sin fuente, nodo hambriento, agotada) |

Cada bloque de Avaritia también muestra su nivel (opción "Mostrar el nivel").

## Escenas de Ponder

Si hay una biblioteca Ponder instalada, este mod registra estas escenas:

- Horno alquímico avanzado, Horno infernal, Taumatorio, Prensa de gólems, Mesa de investigación.
- Altar de infusión (variantes de piedra arcana, antigua y eldritch).
- Estabilizar y activar nodos.
- Cargador de Mesa.
- Los niveles de Avaritia: Hornos alquímicos, Matrices Mnemotécnicas, Estabilizadores de nodos, Transductores de nodos, Cargadores de Mesa.

Están agrupadas bajo la etiqueta *Estructuras multibloque*. Usa la tecla de Ponder sobre el objeto para abrir su escena.

## Errores comunes

- Buscar las descripciones sin tener Jade instalado.
- Desactivar una familia en la configuración de Jade y preguntarse por qué desapareció su información.

## Notas

- Sus valores se ajustan en la configuración de Jade del mod.
