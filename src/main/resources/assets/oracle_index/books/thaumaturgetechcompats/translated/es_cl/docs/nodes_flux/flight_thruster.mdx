## Qué es

El Propulsor de vuelo es un módulo de peto que te deja volar a ráfagas controladas con flujo dimensional. Anula el daño de caída mientras guarde algo de DF.

| Propiedad | Valor |
| --- | --- |
| Flujo dimensional que guarda | 200.000 |
| Coste | 800 DF por segundo de impulso |

## Cómo se usa

1. Infúndelo sobre un Peto de taumio.
2. Póntelo en el pecho y ten un Cargador ambiental cerca para llenarlo.
3. Mantén saltar en el aire para impulsarte hacia arriba, y adelante para avanzar también.
4. Cada ráfaga dura 50 ticks y luego se enfría 10 ticks.

> [!NOTE]- Thaumonomicon: Propulsor de vuelo
> El Propulsor de vuelo se infunde a partir de una pechera de taumio, con tres placas de latón, dos mecanismos complejos, una semilla del vacío y dos resonadores de vis.
> Se lleva en el pecho y almacena Flujo Dimensional, que un cargador ambiental puede rellenar. Mientras mantienes el salto en el aire te impulsa hacia arriba, y también hacia delante si mantienes la tecla de avance, en ráfagas que necesitan un momento para enfriarse. Además anula el daño de cualquier caída mientras conserve flujo. Sin flujo no hace nada.
