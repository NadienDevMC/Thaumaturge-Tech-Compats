## Qué es

El Terraformador arcano de latón alquímico repinta el bioma de la zona de alrededor, columna a columna empezando por sus pies, con el bioma de su **cebo** (un objeto que representa un bioma: arena para un desierto, nieve para la tundra, un brote para un bosque).

| Propiedad | Valor |
| --- | --- |
| Radio | 32 bloques |
| Flujo dimensional que guarda | 2.000.000 |
| DF por columna de 4x4 | 1.500 |
| Columnas por ciclo | 6 |

## Cómo se usa

1. Fabrícalo (el de taumio en la Mesa de trabajo arcana, los demás infundidos alrededor del anterior).
2. Dale DF (un Núcleo de almacenamiento, un Enlace de transmisión o un Extractor de grietas tocándolo).
3. Haz clic derecho con el objeto cebo. Agáchate y haz clic derecho con la mano vacía para recuperar el cebo.
4. Haz clic derecho otra vez para ver su progreso, radio y estado. Los biomas y dimensiones bloqueados en la configuración no se tocan.
