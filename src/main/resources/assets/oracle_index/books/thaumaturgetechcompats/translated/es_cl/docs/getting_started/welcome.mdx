**Thaumaturge Tech Compats** une la magia de Thaumaturge con otros mods: la progresión de Avaritia, el poder del flujo, máquinas movidas por nodos y tres niveles de metal que todas las compatibilidades siguen: **Taumio, luego Latón alquímico, luego Metal del vacío**. Cada nivel necesita el anterior.

Usa los capítulos de la izquierda. **Contenido** tiene una página por función y te dice qué es, cómo conseguirla y cómo ponerla a funcionar paso a paso. Las páginas indican qué mod necesitan: si no tienes ese mod, la función simplemente no está.

**Cómo abrir este libro:** pulsa **H** (la tecla de Oracle Index, se cambia en Controles bajo "Oracle Index") o pasa el cursor sobre cualquier objeto de este mod y usa el enlace del tooltip. Es un visor del lado del cliente: no hay un objeto libro que fabricar.

Casi todo se fabrica con el sistema de investigación del Thaumonomicon. Cada página te dice qué investigación lo desbloquea.
