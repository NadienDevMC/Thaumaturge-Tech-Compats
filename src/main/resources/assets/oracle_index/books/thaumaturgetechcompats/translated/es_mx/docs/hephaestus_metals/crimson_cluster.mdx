## Qué es

El Racimo nativo de Crimson es el cúmulo nativo del metal, como los cúmulos de Thaumaturge.

## Cómo se consigue

Este mod no define ninguna receta para él.

## Cómo se usa

1. Este mod no define receta ni generación en el mundo para él: solo está en la pestaña creativa o lo da otro contenido (paquetes de datos, otros mods).
2. Guárdalo para recetas de otro contenido que lo usen.
